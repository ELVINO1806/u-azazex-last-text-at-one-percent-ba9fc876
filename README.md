Entry for the [make.fun](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876) competition **"Last Text at One Percent"** — the phone's last text at 1% battery, funny, in the phone's own voice.

## Entry

> I'm at 1%. If anyone asks, I died doing what I loved: judging your 2 a.m. searches. Delete the browser history. Goodbye.

- Characters: 120 (limit 200)
- One line, one sentence each — a dying phone's last SMS.

## Why it works

The phone has a stake in dying: it spent its last charge judging the
owner's 2 a.m. searches, and its final act is a favour — delete the
browser history. The joke turns on a specific, relatable detail instead
of a low-battery pun, and the voice stays the phone's throughout.

## Run

```bash
OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program writes exactly the entry line above to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
